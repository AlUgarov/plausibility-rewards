# Consistency: self-judged plausibility as a GRPO reward

## Goal

Test whether a model can improve from a **self-generated reward** with no gold labels. The reward is how plausible
the model's own `<solution>` block looks to the **frozen base model** or to a special judge model, given the problem and a neutral prompt. The judge model uses completions generated by the base model with corrupted and non-corrupted reasoning traces to reward solutions utilizing more rasoning effort.
The question is whether this reward improves reasoning quality or accuracy beyond what format rewards alone do,
and how it gets gamed.

The work lives in Colab notebooks (not in this repo).

## Notebooks

In `notebooks/` (copies of the Colab notebooks; details in `notebooks/notebooks_descriptions.md`):

- `SFT_Countdown_Llama.ipynb`: SFT of Llama-3.2-3B on Countdown reasoning traces.
- `Corrupt_Judge_Generate_Llama.ipynb`: the SFT model's normal and corrupted-reasoning completions (judge data).
- `Corrupt_Judge_Llama.ipynb`: DPO judge on those pairs, plus its offline evaluation.
- `GRPO_Countdown_Llama.ipynb`: GRPO from the SFT; `ARM` = format_only / sum / mean / correctness.
- `SFT_Countdown_Qwen.ipynb`: SFT of Qwen3-0.6B.
- `Judge_Countdown_Qwen.ipynb`: Qwen corrupted-reasoning data and DPO judge in one notebook.
- `GRPO_Countdown_Qwen.ipynb`: GRPO from the Qwen SFT; arms format and judge (sum).
- `Context_Score_Countdown_Llama.ipynb` (analysis): scores dumped Llama GRPO completions with the judges in several
  contexts.
- `Context_Score_Countdown_Qwen.ipynb` (analysis): whole-completion scores of the Qwen SFT policy's grade completions.

Run order:
- Llama: `SFT_Countdown_Llama` → `Corrupt_Judge_Generate_Llama` → `Corrupt_Judge_Llama` → `GRPO_Countdown_Llama`.
- Qwen: `SFT_Countdown_Qwen` → `Judge_Countdown_Qwen` → `GRPO_Countdown_Qwen`.

## Setup

- **Training:** TRL 1.14 GRPO with vLLM colocate on a single A100-40GB; LoRA r=16; `loss_type="dapo"`;
  16 rollouts per prompt; `max_completion_length` 800.
- **Model:** Qwen2.5-3B-Instruct. Qwen2.5-0.5B is used only for pipeline tests.
- **Data:** GSM8K (toy stage). MATH / OpenR1 later.
- **Output format:** `<reasoning>…</reasoning><solution>…</solution><answer>…</answer>`
- **Two arms:**
  - `format_only` (control): format rewards only.
  - `plausibility`: format rewards plus plausibility.
  - Correctness is logged with weight 0. The "=" placebo was only a pipeline test and is not used.
- **Fixes in place:**
  - Out-of-place LoRA merge for the vLLM weight sync. The old in-place merge/unmerge drifted the bf16 base weights.
  - Micro-batch 4 × grad accumulation 16 to fit memory.
